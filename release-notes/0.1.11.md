## What's new

- Pinch the file grid to zoom, like a photo gallery. Cards resize as you move your fingers and snap to whole columns.
- Image and video thumbnails in the drive. They are sharper and stay saved, so they load quickly after you reopen the app.
- Open any file in another app, or share it, from the file menu.
- On phones, one menu panel holds all file actions.
- Faster backups.
- Smaller index: the drive's file list is much more compact.

## Fixes

- The top bar and Settings header no longer sit under the status bar.
- Backups now show the reason when photos or folders can't be read.
- Fewer repeated index messages in the channel during backups.
- Folder and file cards keep their size and layout when the screen changes.
